==============================================================================
1. INTRODUCTION                                                *magickey-intro*

magickey plays a short sine tone from a musical scale on every keystroke,
modelled on the "pentatonic" sound of monkeytype. Samples are rendered once as
WAV files and played through an external player (pw-play, paplay, aplay or
afplay).

Requires Neovim 0.11 or newer.

==============================================================================
2. SETUP                                                       *magickey-setup*

>lua
  require("magickey").setup({
    enabled = true,
    trigger = "insert",          -- "insert" or "all"
    scale = "pentatonic",        -- "pentatonic", "wholetone" or { "C", "E", ... }
    volume = 0.5,                -- 0 .. 1
    max_voices = 8,
    player = nil,                -- e.g. { "paplay" }
    filetypes_exclude = { "TelescopePrompt" },
  })
<

==============================================================================
3. COMMANDS                                                 *magickey-commands*

:Magickey [enable|disable|toggle]                                   *:Magickey*
    Enable, disable or toggle the sounds. Without argument: toggle.

==============================================================================
