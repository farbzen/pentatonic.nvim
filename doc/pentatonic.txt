1. INTRODUCTION                                             *pentatonic-intro*

pentatonic.nvim plays a short sine tone from a musical scale on every
keystroke, modelled on the "pentatonic" sound of monkeytype. Samples are
rendered once as WAV files and played through an external player (pw-play,
paplay, aplay or afplay).

Requires Neovim 0.11 or newer.

==============================================================================
2. SETUP                                                    *pentatonic-setup*

>lua
  require("pentatonic").setup({
    enabled = true,
    trigger = "insert",          -- "insert" or "all"
    scale = "pentatonic",        -- "pentatonic", "wholetone" or { "C", ... }
    volume = 0.15,               -- 0 .. 1
    volume_step = 0.05,          -- step of :Pentatonic louder/quieter
    max_voices = 16,
    player = nil,                -- e.g. { "paplay" }
    filetypes_exclude = { "TelescopePrompt" },
  })
<

==============================================================================
3. COMMANDS                                              *pentatonic-commands*

:Pentatonic [enable|disable|toggle|louder|quieter]               *:Pentatonic*
    Enable, disable or toggle the sounds. Without argument: toggle.
    `louder` and `quieter` change the volume by `volume_step` (clamped to
    0 .. 1) for the current session.
